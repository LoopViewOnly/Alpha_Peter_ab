Core Components Overview

CPU (Processor)

The brain of the computer that executes instructions, handles logic, and manages system tasks.

  • Measured in Cores, Threads, and GHz
  • Determines multitasking & single-core speed

Explore CPU Specs

GPU (Graphics Card)

Specialized hardware designed for rendering 3D graphics, video output, and parallel AI workloads.

  • Measured in VRAM, Clock Speed, and Shaders
  • Essential for gaming, 3D rendering, and video editing

Explore GPU Specs

RAM (System Memory)

High-speed temporary storage that holds active applications and data for instant CPU access.

  • Measured in Capacity (GB), Speed (MT/s), and Latency
  • Prevents slowdowns when running multiple programs
