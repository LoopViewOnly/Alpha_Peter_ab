Central Processing Unit (CPU)

The CPU interprets and executes instructions from hardware and software. Modern processors balance high single-core speeds with multi-core parallel processing.

Key CPU Specifications Explained

Cores & Threads

Cores are individual processing units inside the CPU. Threads are virtual pathways that allow each core to handle two tasks simultaneously.

Clock Speed (GHz)

Indicates how many cycles a processor executes per second. Base clock is the standard operating speed; Boost clock is the maximum speed under heavy load.

Cache & TDP

L3 Cache is ultra-fast on-chip memory that boosts gaming and app speed. TDP (Watts) measures heat output and cooling requirements.
