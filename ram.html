Random Access Memory (RAM)

RAM acts as your computer's short-term working memory. More capacity allows you to run heavier applications and keep dozens of browser tabs open without slowing down.

Key RAM Specifications Explained

Generation (DDR4 vs DDR5)

DDR5 is the modern standard, offering double the bandwidth, higher capacities per stick, and better power efficiency compared to older DDR4.

Transfer Speed (MT/s)

Measured in MegaTransfers per second (e.g., 6000 MT/s). Higher speeds let the CPU read and write data faster.

CAS Latency (CL)

The delay (in clock cycles) between requesting data and receiving it. Lower CL numbers (such as CL30) indicate faster response times.
